# SM64 LiveSplit Autosplitter

An autosplitter for Super Mario 64 speedrunning, built specifically for **Project64 1.6**.

## Supported Categories & Versions

- **Japanese (JP) Version:** 0-Star, 1-Star, 16-Star, 120-Star
- **North American (US) Version:** 70-Star

## Route Notes

- **16-Star:** Supports both LBLJ and non-LBLJ routes.
- **70-Star:** Supports both Island Hop and Beginner/Standard routes.
- **120-Star:** Supports both LBLJ and non-LBLJ routes.

## How to Use

1. Download the `.asl` file corresponding to your category.
2. In LiveSplit, right-click and go to **Edit Layout** -> add a **Scriptable Auto Splitter**.
3. Point the script path to your downloaded `.asl` file.
